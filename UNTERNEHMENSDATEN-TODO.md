# Interne Unternehmensdaten-Checkliste

- [ ] Gewerbeanmeldung abschließen.
- [ ] Steuerliche Erfassung abschließen.
- [ ] Prüfen, ob eine Umsatzsteuer-Identifikationsnummer vorhanden ist.
- [ ] Prüfen, ob eine Wirtschafts-Identifikationsnummer vorhanden ist.
- [ ] Ausschließlich die tatsächlich zutreffende Nummer in `src/config/site.ts` eintragen.
- [ ] Niemals die persönliche Steuer-Identifikationsnummer veröffentlichen.
- [ ] Niemals die gewöhnliche Steuernummer des Finanzamts veröffentlichen.
- [ ] Rechtstexte vor dem endgültigen Geschäftsbetrieb fachlich prüfen lassen.

Die öffentlichen Steuerabschnitte im Impressum werden nur gerendert, wenn im jeweiligen Konfigurationsfeld tatsächlich ein Wert eingetragen ist.
